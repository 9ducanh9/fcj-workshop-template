# Xây dựng workflow xử lý AI

Phần này xây dựng luồng xử lý chính:

1. Chuẩn bị transcript hoặc audio input.
2. Chạy transcription khi dùng audio.
3. Phân tích transcript bằng Amazon Bedrock.
4. Lưu và kiểm tra báo cáo coaching.

Để demo đầu tiên ổn định, hãy dùng transcript input trước. Sau đó mới test audio input với Amazon Transcribe.
