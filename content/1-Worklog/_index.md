# 12-Week Project Worklog

This section records twelve weeks of my FCAJ AWS Bootcamp journey, from initial research and requirements analysis to implementation, AWS deployment, production verification, and final documentation. Each weekly entry presents the work completed, results achieved, and lessons learned while developing the final project.

The worklog follows the development of **LiveCap**, a browser-based application that delivers real-time Vietnamese-English captions using Amazon Transcribe Streaming, Amazon Translate, and an AWS cloud architecture.
