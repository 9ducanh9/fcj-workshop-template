# Week 3 Worklog

## Work Completed

- Evaluated the original real-time AI communication assistant idea.
- Listed technical risks: streaming latency, diarization accuracy, privacy, demo stability, and scope explosion.
- Compared three MVP options: post-conversation coach, interview practice coach, and near-real-time insight board.

## Results Achieved

- Selected the post-conversation Cognitive Communication Coach as the final MVP.
- Defined the target users: students, interns, junior engineers, interview candidates, and presentation learners.
- Wrote the first version of the project problem statement.

## Learning Outcomes

- Reducing scope is not weakening a project; it can make the architecture more credible.
- A project should have a clear success path and fallback path.
