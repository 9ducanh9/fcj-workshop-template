# Week 1 Worklog

## Work Completed

- Joined the FCAJ AWS Bootcamp orientation and reviewed the final project requirements.
- Studied the FCAJ workshop template structure and report sections.
- Reviewed basic AWS service categories: compute, storage, database, networking, security, and monitoring.
- Started brainstorming the original idea: an AI assistant that helps users think better during conversations.

## Results Achieved

- Understood that the final deliverable must be a bilingual workshop website.
- Identified the required sections: student information, worklog, proposal, blogs, events, workshop, self-evaluation, and feedback.
- Created an initial list of possible AWS services for the project.

## Learning Outcomes

- AWS projects must start from a real user problem, not from using as many services as possible.
- A bootcamp final project must be reproducible and defendable, not only impressive as an idea.
